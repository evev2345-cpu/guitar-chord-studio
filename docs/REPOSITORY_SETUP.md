# GitHub 저장소 구성과 로컬 실행

이 저장소는 기타 코드 분석기의 개발 소스, 테스트, 계약·검증 문서와 일부 검수 그림을 보관한다. 현재 마일스톤은 코드 분석기와 로컬 웹앱이며, 타브 생성과 유튜브 확장은 후속 작업이다.

## 포함 범위

- Python 오디오·화성·손·지판 분석과 실험·평가 스크립트, 테스트.
- Chord Studio 웹앱의 서버·브라우저 코드.
- 개발일지와 연구 보고서, 일부 최신 비교 그림·통계.
- 비밀값이 없는 `.env.example`과 의존성 기록.

`.env`, API 키, 가상환경, 캐시, 업로드, 실행 로그, 모델 가중치, 원본 영상·음원, 다운로드한 GuitarSet/EGDB/IDMT와 대량 프레임·추론 결과는 포함하지 않는다. 로컬 원본 파일을 삭제하거나 이동하지 않았다. 일부 과거 보고서의 사진·미디어 링크와 데이터 기반 테스트는 로컬 자료가 있어야 사용할 수 있다. GitHub 저장소만으로 전체 실험 데이터가 복구되는 구성은 아니다.

## 웹앱 실행

현재 개발 환경은 Windows PowerShell이다. 기존 분석 환경이 있는 PC에서:

```powershell
python chord_web_server.py --open
```

`http://127.0.0.1:8765`로 접속한다. 파일을 올려 분석하고 재생 시간에 맞는 코드 후보를 확인한다. 자세한 조작은 [웹앱 사용법](../webapp/README.md)에 있다.

새 PC에서는 Python 의존성, PATH의 ffmpeg/ffprobe, 모델 추론용 `.venv-audio-model`을 별도로 준비해야 한다. 일반 오디오 의존성은 `dataset/audio_analysis/requirements.txt`, 기존 모델 환경 스냅샷은 `docs/audio-model-requirements.lock.txt`, 음원 분리 환경은 `docs/audio-separation-requirements.lock.txt`에 있다. 모델 환경 경로는 현재 Windows `.venv-audio-model/Scripts/python.exe`를 사용한다. 모든 연구용 선택 의존성을 한 환경에 설치하는 방식은 검증하지 않았다.

웹앱의 샘플 버튼은 제외된 기존 기타 분리음과 모델 출력이 필요하다. 새 PC에서 샘플이 없어도 환경을 준비한 후 직접 파일을 업로드해 새 분석을 실행할 수 있다. 모델 음 후보는 MIDI 38~88이며 파형 주파수 컷을 추가하지 않는다. 웹앱에는 비전·기타 분리 자동화가 아직 연결되지 않았다.

## 외부 자료

- Basic Pitch는 기존 설치된 사전학습 ONNX 모델을 사용하며 모델 출처는 추론 실행의 `model.json`에 기록한다.
- MediaPipe 손 랜드마크 등 다운로드 가중치는 별도로 준비한다.
- GuitarSet, EGDB, IDMT 자료의 이용 조건은 각 원 출처를 따른다. 원본을 이 저장소에 재배포하지 않는다.
- 이 업로드 준비 작업에서 프로젝트의 새 라이선스나 제삼자 자료의 재배포 허가를 임의로 부여하지 않았다.

## 검증 상태

웹앱 작업에서 기존 회귀 포함 184개 테스트와 프런트엔드 계약 검사 5개를 통과했고, EGDB 비교의 별도 검사 3개도 통과했다. 이 기록은 로컬 데이터가 있던 개발 환경에서 실행한 결과이며 새 clone에서의 전체 통과를 뜻하지 않는다. 브라우저 자동 접근 승인 차단으로 웹앱 렌더링·조작 검수는 아직 미완료다.

API를 호출하는 연구 스크립트가 있으므로 테스트 전체 자동 수집을 임의로 실행하지 않는다. 파일명에 `test_`가 있어도 과거 실험 실행 스크립트인 경우가 있다. 각 보고서에 적힌 오프라인 검증 명령을 사용한다.

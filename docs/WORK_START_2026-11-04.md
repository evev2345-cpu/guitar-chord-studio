재생성 가능한 루트 Python 캐시, 음원 분리 설치 캐시, 임시 콘솔 요약3개를 제거했다. 총5경로의 준비 목록 기준 논리 파일 크기는587,362,555바이트다. 하드링크가 있어 실제 회수 용량과 같지 않을 수 있다.

사용 여부가 불확실한 실험코드, 테스트, 모델, 원본·가공 데이터, 버전된 run, 검수 자료, 학습/실행 로그는 보존했다. 전용 음원 분리 환경과 다운로드된 모델도 유지했다. 제거·보존 검사는 `CLEANUP_2026-11-04.json`에 기록했다. 새 설치·다운로드는 없다.

## 오늘의 최우선 목표

frame210의 **손가락 대응 오류를 안전하게 차단하고, 원시 스켈레톤 단위로 대안을 검토**한다. 현·오디오 가중치 개선보다 먼저 수행한다.

![사용자가 대응 오류를 확인한 원시 ROI 스켈레톤](../dataset/hand_skeleton_only/runs/frame210_20261103_v1/baseline_roi_hand_zoom.png)

사용자가 엄지/검지는 대체로 맞지만 중지체인이 중지+약지를 혼합하고 실제 약지를 소지로 인식해 소지가 누락됐다고 확인했다. 정밀좌표·다른crop/프레임·실제접촉까지 검수한 것은 아니다.

원본 검수: `dataset/hand_analysis/human_review_20261103/frame210_finger_identity_review.json`.

### 손 담당 P0

1. frame210의 원시21점·프레임/픽셀/관측 branch를 식별하는 고정 회귀를 만든다. 사용자 검수의 scope를 엄격하게 보존한다.
2. 검수된 baseline ROI의 중지/약지/소지 체인을 해부학적으로 유효한 운지 근거에서 제외하는 sidecar/adapter를 만든다. 높은 칸질량도 이를 해제하지 못하게 한다. 다른crop 전체를 일괄오류로 처리하지 않는다.
3. medoid가 해당원시관측에서 왔는지 계보를 확인한다. 손가락별 medoid를 단일 실제 스켈레톤처럼 합치지 않는다. 관측 근거가 불명확하면 미확정으로 둔다.
4. 같은 프레임의 기존 단일손 전체21점 대안을 원본 위 연결선으로 나란히 비교한다. 이름만 바꾸거나 숨은소지 좌표를 만들어 복구하지 않는다. 로컬로 가능한 진단을 수행하고 불가능한 지점을 기록한다.
5. 새 유효성 계약을 포함한 hand-cell fixture를 새 run에 제출한다. 원본좌표와 이전 run은 보존한다. 원본/스켈레톤/실패사진을 보고서 본문에 넣는다.

### 화성/결합 담당 P0

1. 손가락 의미/체인 유효성 상태를 fusion 전 단계에서 적용한다. invalid와 unknown, 낮은점수와 입력결측을 구분한다.
2. 오류체인의칸·음·코드조합이 영상/오디오 가중치나 큰 위치질량으로 되살아나지 않도록 검사한다. 원래관측은 진단자료로 보존한다.
3. 정확한 hand 관측 계보가 맞는 경우에만 사용자 검수를 적용한다. 같은frame의 다른crop이나다른시점에 무차별전파하지 않는다.
4. 손 담당의 새 실제 fixture가 오기 전에는 명시적합성계약으로 검사하고, 도착하면 원본/PTS/grid/관측계보를 검증해 재생한다. 예전결과를 덮어쓰지 않는다.

## 완료 기준

오류스켈레톤의 중지/약지/소지를 정상운지로 사용하지 않는 회귀가 통과하고, 실제 fixture 연결과 원본/스켈레톤 사진으로 그 상태를 검토할 수 있어야 한다. 해부학적으로 올바른 손 복구와 오류 차단은 별개로 보고한다. 실제복구가 확인되지 않으면 정확도가 개선됐다고 주장하지 않는다.

현재 지판·가상grid·오디오 자료는 보존해 재사용한다. 사용자가 요청한 보고서 사진 첨부 규칙을 유지한다. 이번 착수는 손·결합 담당을 우선하며 지판·오디오에 새 실험을 추가하지 않는다.

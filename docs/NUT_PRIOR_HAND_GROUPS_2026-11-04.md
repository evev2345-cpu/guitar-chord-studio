# 너트 위치 분포와 손 단위 채점: 4812 재검사

## 변경

`global_fretting_hand.py`에 너트 중심의 넓은 타원형 가우시안 위치 사전 점수(`nut_prior`)를 추가했다. 지판 길이 방향 표준편차는 지판 길이의 0.85배, 수직 방향은 지판 두께의 1.8배다. 너트/지판 좌표에 상대적인 분포라 화면의 특정 x좌표를 우대하지 않는다. 높은 프렛으로 이동해도 점수가 완만하게 감소한다. 확률로 보정한 값이 아니라 운지 손 후보를 비교하는 휴리스틱이다.

기본 점수는 지판 근접 0.50, 너트 사전 점수 0.35, 사용 가능한 이전 위치 0.15의 정규화 가중합이다. 방향은 기존처럼 최대0.15 추가 가점이다. 최저점수0.60/두 손 차이0.12 조건은 유지했다. 모든 근거와 수식 버전은 결과 JSON에 저장한다.

회전별로 먼저 손을 하나 고르던 구조를 바꿨다. 전체 후보를 원본 좌표로 복원한 뒤 손가락 뿌리 중심 위치로 같은 실제 손 후보를 묶는다. 묶음 내 모든 중심 간 거리가 영상 대각선의 0.08배 이하여야 하고 같은 회전의 두 손은 같은 묶음에 넣지 않는다. 각 손의 역할 점수는 구성 후보 점수의 중앙값이다. 검출 횟수는 역할 가점으로 사용하지 않는다. 우선 손 묶음을 고른 다음 그 묶음 안에서 실제 추론 전체21점 하나를 선택한다. 확대 단계에서도 원래 선택 손과 공간적으로 일치하는 후보만 허용한다.

## 재현과 검증

- 주변49프레임: `python review_middle_temporal.py --output dataset/hand_analysis/runs/middle_temporal_200s_20261104_v3_nut_groups`
- 희소12프레임: `python review_global_fretting.py --output dataset/hand_analysis/runs/global_fretting_20261104_v3_nut_groups`
- 테스트: `python -m unittest test_global_fretting_hand test_fretting_hand_skeleton test_hand_anatomical_validity test_hand_fret_tracker test_hand_cell_distribution test_hand_frame_contract test_kim_hand_review test_cell_audio_fusion -q` — 67개 통과.

테스트에는 실제4812 후보의 순서를 뒤집어도 운지 손을 선택하는 회귀 검사, 운지 손1회 대 타현 손4회에서 빈도가 역할 점수를 대신하지 않는 검사, 같은 회전의 양손을 합치지 않는 검사, 높은 프렛쪽 합성 후보 유지 검사를 포함했다. 원본 영상/프레임 식별과 픽셀해시는 기존 진단과 동일하게 보관한다. 지판은 기존 수동 기준을 현재 프레임에 텍스처 정렬한 잠정 근거다.

남은 한계는 손이 가까이 겹칠 때 위치 기반 묶음의 모호함, 지판 부재 시 근거 부족, 관절 오검출, 관측 방향이 적은 후보의 불확실성이다. 해부학적 타당성과 실제 접촉은 여전히 unknown이며 자동으로 정답 처리하지 않는다.

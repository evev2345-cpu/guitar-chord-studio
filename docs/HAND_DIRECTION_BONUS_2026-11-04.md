# 손 방향을 추가 가점으로 변경

## 변경

`global_fretting_hand.score_hand`의 방향 가중 평균을 제거했다. 지판 근접(가중치 0.50)과 유효한 이전 위치(0.15)의 사용 가능한 근거를 정규화해 기본 점수를 계산하고, 여기에 위쪽 방향 점수 × 0.15만 추가한다. 방향이 낮아도 기본 점수는 감소하지 않는다. 두 공간 근거가 모두 없으면 기본 점수는 0이고, 방향만으로는 0.60 선택 문턱을 통과할 수 없다. 점수는 최대 1.15인 비교용 값이며 확률이 아니다. 두 손의 차이가 0.12 미만이면 보류하는 조건은 유지했다.

## 실제 PTS 214.000000초 / 프레임5135

수정 전 네 회전의 점수는 0.539~0.570으로 모두 보류였다. 수정 후 지판 기본 점수 0.9125~0.9214에 방향 추가점 0.0004~0.0101이 더해져 최종 점수는 0.9151~0.9315가 됐다. 네 회전 모두 해당 운지 손을 선택했다. 확대 재검출은 선택 후보를 반환하지 못해 전체 화면에서 얻은 스켈레톤을 반환했다(`output_stage=global`).

아래 왼쪽은 원본에 잠정 지판 문맥을 표시한 그림, 가운데는 전체 화면 후보와 선택 결과, 오른쪽은 선택 손 확대다. 노랑=잠정 지판, 반투명 초록=연장 문맥 개념도, 회색=손 후보 경계. 스켈레톤 청록=검지, 초록=중지, 주황=약지, 자홍=새끼, 흰색=엄지다. 관절은 모두 모델 추정이며 수동 수정하지 않았다.

![214초 수정 후 운지 손 선택과 남은 관절 오류](../dataset/hand_analysis/runs/global_fretting_20261104_v2_direction_bonus/pts_214.00.png)

원본과 비교하면 운지하는 손을 선택한 것은 맞지만 스켈레톤 손목/손가락 연결은 부자연스럽다. 낮았던 방향 점수에는 관절 오검출 영향이 있는 것으로 보이며, 선택 복구를 스켈레톤 정확도 개선으로 해석하면 안 된다. 해부학적 타당성과 실제 접촉은 계속 unknown이다.

수정 전 보류 결과도 보존했다.

## 재검사

동일 195~225초 12프레임을 새 경로로 재실행했다. 선택 후보 반환은 이전 11/12에서 12/12가 됐다. 이는 정확도 측정이 아니다. 198초 최종 2방향, 206초·217.25초 최종 1방향 후보는 여전히 `insufficient_views_candidate`다. 200초 중지 오연결을 포함한 관절 오류도 해결되지 않았다. 전체 12개에 대한 관절 정답 라벨 평가는 수행하지 않았다.

실행: `python review_global_fretting.py --output dataset/hand_analysis/runs/global_fretting_20261104_v2_direction_bonus`. 기존 결과를 덮어쓰지 않고 점수의 기본값/추가점/버전을 JSON에 기록한다.

검증: `python -m unittest test_global_fretting_hand test_fretting_hand_skeleton test_hand_anatomical_validity test_hand_fret_tracker test_hand_cell_distribution test_hand_frame_contract test_kim_hand_review test_cell_audio_fusion -q` — 63개 통과. 방향이 지판 기본 점수를 낮추지 않는 성질, 방향만으로 선택되지 않는 성질, 실제 214초 네 회전 후보의 선택 복구를 추가 검사했다.

다음 과제는 선택된 손의 관절 오류 판별과 확대 실패 분석이다. 운영 화성/접촉 판정에 검증 완료 좌표로 자동 전달하지 않는다.

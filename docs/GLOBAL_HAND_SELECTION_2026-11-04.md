최신 v3: [너트 위치 분포·손 단위 채점과 4812 검증](NUT_PRIOR_HAND_GROUPS_2026-11-04.md).

후속 변경: 방향 가중 평균을 추가 가점으로 수정했다. 아래는 v1 실험 기록이며 최신 수식과 214초 선택 복구는 [방향 추가 가점 보고서](HAND_DIRECTION_BONUS_2026-11-04.md)를 참조한다.

## 구현 내용

고정 탐색 좌표를 사용하지 않는 `global_fretting_hand.detect_global_fretting`을 추가했다. 전체 프레임에서 최대 두 손을 4개 회전 방향으로 검출하고, 원본 좌표로 돌린 각 손에 가점을 계산한다. 방향은 손목에서 검지·중지·약지·새끼의 뿌리 중심으로 향하는 벡터를 사용한다. 위를 향할수록 점수가 높지만 필수 조건은 아니다.

초기 가중치는 방향 0.35, 지판 거리 0.50, 이전 위치 0.15다. 이용 가능한 근거만으로 가중합을 정규화한다. 확률이 아닌 미보정 휴리스틱 점수이며 실측 정답으로 최적화한 값이 아니다. 최고 점수 0.60 미만 또는 한 회전에서 두 손의 점수 차이 0.12 미만이면 그 회전의 선택을 보류한다. 회전별 선택 중 실제 21점 전체 후보 하나를 고르며 3개 미만 관측은 부족한 근거로 표시한다.

지판 길이 전체에 거리 가점을 적용한다. 지판 두께를 기준으로 너트 바깥 2배, 몸통 방향 1배를 연장한 중심 선분을 만들고, 손가락 뿌리 4개와 끝 4개의 거리 중앙값에 가우시안 감쇠를 적용한다. 손목은 거리 계산에서 제외한다. 너트 바깥에서도 가점이 이어지며 경계에서 갑자기 끊기지 않는다. 너트 방향은 코너 순서(너트위, 몸통위, 몸통아래, 너트아래)에서 가져온다. 다른 지판 형식은 이 순서로 어댑트해야 한다.

선택한 손 전체 경계로 확대해 다시 양손 검출과 점수 선택을 수행한다. 확대 단계가 실패하면 전체 화면에서 선택한 후보를 명시적으로 반환한다. 출력 `output_stage`에서 global/refined를 구분한다. 실제 한 추론의 전체 관절을 유지하며 해부학적 타당성과 접촉 여부는 unknown으로 둔다. 원래 단일 손 분석기의 기본 설정은 유지하고 새 실행 경로에서 `num_hands=2`를 사용한다.

## 지판 연결 범위

이번 영상 실험의 지판은 기존 프레임120 수동 기준을 현재 프레임의 지판 텍스처에 LK/RANSAC으로 정렬한 잠정 결과다. 12개 샘플 모두 정렬 검사는 valid였으나 독립적인 자동 지판 정답 검증은 아니다. 정렬이 valid가 아니면 해당 프레임의 거리 가점을 생략하고 전체 화면 탐색을 계속한다. 오래된 지판을 현재 위치인 것처럼 쓰지 않는다.

이전 위치 가점은 시간 간격이 0초 초과 0.5초 이하일 때만 적용한다. 이번 희소 샘플 중 195.5초와 196초에만 사용됐다. 프레임 전체를 순차 처리한 추적 성능은 아직 평가하지 않았다.

## 실행 결과와 실제 사진

195~225초 기존 12프레임을 재사용했다. 고정 확대는 7/12, 이전 자동 확대는 10/12, 새 전체 화면 경로는 11/12에서 후보를 반환했다. 기존 넓은 크롭 4방향 방식도 11/12였으므로 모든 기존 방식보다 검출률이 높다고 주장하지 않는다. 후보 수는 손가락 정확도가 아니다. 198초는 2방향, 206초는 1방향 후보라 근거 부족 상태다. 202·206·217.25초 출력은 확대 재검출 실패 후 전체 화면 후보를 사용했다.

아래 사진은 왼쪽 원본+잠정 지판 문맥, 가운데 전체 화면 후보 범위와 선택 스켈레톤, 오른쪽 선택 손 확대다. 노랑=잠정 지판, 넓은 반투명 초록선=연장 문맥 개념도(정확한 점수 등고선은 아님), 회색=검출 손 경계다. 스켈레톤 청록=검지, 초록=중지, 주황=약지, 자홍=새끼, 흰색=엄지이며 모두 모델 추정이다. 점은 표시하지 않았다.

## 검증과 남은 작업

재현 명령: `python review_global_fretting.py`. 결과는 `dataset/hand_analysis/runs/global_fretting_20261104_v1/result.json`. 원본 경로·영상 ID·프레임 인덱스·실제 PTS·픽셀 해시를 기존 결과에서 유지하고, 회전별 두 손의 점수/가점/선택과 지판 정렬 근거를 기록한다. 전체 화면에는 화면 TAB/코드도 보이지만 텍스트나 코드값을 읽어 선택 점수로 사용하지 않는다.

검증 명령: `python -m unittest test_global_fretting_hand test_fretting_hand_skeleton test_hand_anatomical_validity test_hand_fret_tracker test_hand_cell_distribution test_hand_frame_contract test_kim_hand_review test_cell_audio_fusion -q` — 61개 통과. 방향과 지판으로 두 손 구분, 너트 확장/거리 감쇠, 지판 이동 시 상대 위치 유지, 동점/부재/낮은 근거의 보류, 잘못된 지판 거부를 검증했다.

다음은 214초 보류 원인과 손 방향 변화에 대한 점수 조정, 연속 프레임 및 높은 프렛 이동에서 손 선택 검증, 운지 손의 실제 관절 정답을 이용한 중지·약지·새끼 오류 평가다. 점수와 문턱값은 검수 자료로 평가한 뒤 조정해야 한다. 새 경로는 오프라인 비교용으로 구현했으며 화성/접촉 판정에 검증 완료 좌표로 자동 전달하지 않는다.

# 4823 앞뒤 네 프레임 검사

현재 원본 우선/조건부 회전 v4를 변경하지 않고 프레임4821~4825를 순차 디코드해 각각 독립 IMAGE 추론했다. 이전 위치 가점이나 좌표 보간은 사용하지 않았다. 기존 프레임4821~4823 결과와 같은 손 선택 결과를 재현했고4824~4825를 추가 확인했다.

모든 프레임은 원본0도에서 타현 손만 검출되어 추가 회전을 실행했다. 선택된 네 프레임 모두 확대 재검출이 실패해 전체 화면 후보를 반환했다.4821은2방향, 나머지 선택 프레임은1방향 관측으로 모두 `insufficient_views_candidate`다. 점수는 보정된 확률이나 해부학적 신뢰도가 아니다.

원본을 보면 운지 손은 다섯 프레임 모두 계속 존재하고 자세도 유사하다.4823에서 손이 사라지거나 장면이 전환된 것이 아니라, 이미 검출이 약한 구간에서 한 프레임의 전체 화면 손 검출이 누락된 것으로 판단한다. 내부 원인이 미세한 모양 변화인지 검출 문턱 때문인지는 확정할 수 없다. 역할 채점에서 운지 손을 탈락시킨 사례는 아니다.

사진 위는 원본, 아래는 실제 선택 스켈레톤이다. 프레임/실제PTS는 패널별 표기. 청록=검지, 초록=중지, 주황=약지, 자홍=새끼, 흰색=엄지이며 모두 추정이다.4823은 보류라 선이 없다. 고정 사진 뷰는 비교용이고 실제 검출 입력은 전체 화면이다.

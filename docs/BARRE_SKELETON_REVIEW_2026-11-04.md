# 3:15 이후 바레 손 스켈레톤 검토

사용자가 알려 준 바레 시작 위치를 반영해 실제 PTS 195~225초의 12개 프레임을 검사했다. 장면 전환이 없는 연속 촬영이라는 사용자 정보를 전제로 삼되, 전체 영상의 장면 전환 유무를 검사했다고 주장하지 않는다. 손 이동과 자세 변화는 계속 발생한다.

## 변경과 결과

`fretting_hand_skeleton.py`에 현재 프레임의 전체 손 후보 경계로 정사각형 크롭을 만드는 `hand_bounding_crop`과 2단계 `detect_adaptive`를 추가했다. 넓은 영역에서 손 후보를 찾고 해당 손을 확대해 다시 추론한다. 각 단계는 4개 회전 방향으로 독립 IMAGE 추론하며, 21점 전체가 실제 한 번의 추론에서 나온 후보를 선택한다. 손가락별 점 혼합, 수동 좌표 수정, 이전 프레임 좌표 보간은 하지 않는다.

| 방식 | 스켈레톤 후보가 나온 프레임 / 검사 프레임 |
|---|---:|
| 기존 넓은 크롭, 4방향 후보 선택 | 11/12 |
| 앞서 개선한 고정 확대 크롭 | 7/12 |
| 현재 프레임에 맞춘 확대 크롭 | 10/12 |

이 수치는 검출 후보 존재 여부이며 손가락 구분 정확도가 아니다. 기존 넓은 크롭도 이번 비교에서는 4방향으로 실행했으므로 과거 단일 추론 결과와 구분해야 한다. 자동 확대가 모든 방식보다 우수하다는 결과는 아니다. 운영 파이프라인 기본값은 교체하지 않았다.

검사 PTS: 195, 195.5, 196, 198, 200, 202, 206, 210, 214, 217.25, 220, 225초. 202초와 214초 자동 확대는 4방향 중 2방향에서만 후보가 나와 `insufficient_views_candidate`다. 206초에는 고정 크롭 후보가 있지만 자동 확대가 실패한다. 모든 결과의 해부학적 타당성과 실제 현 접촉은 unknown이다.

## 원본과 비교 사진

모든 그림은 왼쪽부터 원본, 기존 넓은 크롭 후보, 앞서 개선한 고정 확대 크롭, 현재 프레임 자동 확대 후보다. 선은 관측 모델의 추정 스켈레톤이다. 청록=검지, 초록=중지, 주황=약지, 자홍=새끼, 흰색=엄지. 점은 표시하지 않았다.

### PTS 196.000000초, 프레임 4703

고정 확대 크롭은 손 이동을 따라가지 못해 누락했다. 자동 확대는 중지·약지·새끼의 별도 선을 복구했으며 원본의 굽힌 중지와 두 바깥 손가락에 시각적으로 대응한다. 정밀 관절 좌표와 실제 접촉은 미확정이다.

### PTS 200.000000초, 프레임 4799 — 잘못된 후보

자동 확대의 초록 중지 끝이 실제 굽힌 중지보다 검지 쪽으로 올라간다. 회전별 모델 합의가 있어도 손가락 연결을 보증하지 못한다. 이 사례는 정확한 운지 후보로 승인하지 않는다.

세 방식 모두 후보를 얻지 못했다. 실패를 이전 좌표로 채우지 않았다.

고정 확대 크롭은 누락하고 자동 확대는 후보를 다시 얻는다. 후보 복구와 해부학적 정답 여부는 별개다.

## 재현과 검증

실행: `python review_barre_skeleton.py --output dataset/hand_analysis/runs/barre_skeleton_20261104_v1`.

결과 JSON과 각 원본 PNG는 같은 실행 폴더에 보관했다. 실제 영상 PTS 목록을 사용했고 원본 영상 SHA256과 프레임 픽셀 SHA256을 기록했다. 화면 TAB/코드는 모델 입력 크롭에 포함하지 않으며 정답으로 사용하지 않았다.

검증: `python -m unittest test_fretting_hand_skeleton test_hand_anatomical_validity test_hand_fret_tracker test_hand_cell_distribution test_hand_frame_contract test_kim_hand_review test_cell_audio_fusion -q` — 57개 통과. 크롭의 영상 경계 처리, 잘못된 좌표 거부, 손 후보 부재 시 좌표를 만들지 않는 동작을 추가 검증했다. 테스트 통과는 실제 영상 정확도를 의미하지 않는다.

다음 작업은 200초 손가락 오연결과 206/217.25초 누락을 중심으로 넓은 크롭과 확대 후보의 선택 기준을 검증하는 것이다. 연속 촬영 특성을 이용하는 시간축 손가락 연결 검사는 아직 구현하지 않았다. 바레의 검지 다중 현 접촉은 손끝 하나로 판정할 수 없으므로 스켈레톤 타당성 검증 후 별도 접촉 모델과 오디오 근거로 다뤄야 한다.

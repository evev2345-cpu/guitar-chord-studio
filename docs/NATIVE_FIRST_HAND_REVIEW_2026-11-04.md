# 원본 우선 검출, 필요할 때만 추가 회전

## 변경

`FrettingHandSkeletonDetector.detect`에 `quarter_turns` 인자를 추가했다. 기존 호출은 여전히4방향이며, 새 전체 화면 운지 손 경로는 `detect_native_first`를 통해 원본0도만 먼저 실행한다. 전체 화면과 선택 손 확대 단계에 각각 적용했다.

원본에서 손 선택이 보류되거나, 역할점수가0.80 미만이거나, 두 손 점수차가0.20 미만일 때만90/180/270도 추론을 추가한다. 이미 실행한0도는 재실행하지 않는다. 이후 동일한 너트 사전 점수와 손 묶음 채점으로 선택한다. 기존 최종 선택 기준0.60/차이0.12는 유지한다. 따라서 약한 후보는 추가 검사 대상이면서 최종 후보로는 남을 수 있다.

회전 실행 여부·사유·원본 단계 채점·추론 횟수를 전체/확대 단계별 JSON에 기록한다. 이 기준은 운지 손 역할의 근거이며 관절 정확도나 확률이 아니다. 원본 한 방향만 통과한 결과는 단일 관측이라는 기존 상태를 유지한다. 관측방향 수가 적다는 이유만으로 무조건 추가 회전하면 모든 프레임이4방향이 되므로 회전 결정에는 그 수를 사용하지 않는다. 관절별 불확실성 검사는 이번 변경 범위에 포함하지 않았다.

## 4812와 주변49프레임 비교

실제 PTS199.000000~201.000000초/프레임4775~4823을 이전 v3와 같은 독립 IMAGE 조건에서 재실행했다. 이전 위치 가점·평활화 없이 공간 근거만 사용했다. 픽셀해시와 실제PTS를 보존했고 이전 출력은 덮어쓰지 않았다.

| 항목 | 매번4방향 v3 | 원본 우선 v4 |
|---|---:|---:|
| 운지 손 위치 후보 반환 | 48/49 | 48/49 |
| 반대 손 선택 | 0 | 0 |
| 보류 | 프레임4823 | 프레임4823 |
| 모델 추론 횟수(전체+확대) | 388 | 187 |

추론 호출 수는51.8% 감소했다. 실행시간51.8% 감소를 측정한 것은 아니다. 새 방식은 전체 화면49회 중18회, 확대48회 중12회에 추가 회전을 실행했다. 손 선택 결과가 같다는 것은 역할/위치 수준의 비교이며21개 관절 좌표까지 동일하다는 의미가 아니다.

4812(PTS200.541667초)에서는 원본0도에 타현 손만 나와 점수 기준에서 보류됐다. 이어 추가 회전에서 운지 손을 발견했고 같은 손끼리 묶은 후 운지 손을 선택했다. 확대에서는 유효 결과가 없어 전체 화면 후보를 반환했다. 이 프레임은 전체4회+확대4회로8회 추론이 필요했다. 검출이 쉬운4808은 전체1회+확대1회인2회로 끝났다.4812 운지 손은 여전히 한 방향 관측이므로 해부학적 정확성은 미확정이다.

## 검증

주변 재현: `python review_middle_temporal.py --output dataset/hand_analysis/runs/middle_temporal_200s_20261104_v4_native_first`.

희소구간 재현: `python review_global_fretting.py --output dataset/hand_analysis/runs/global_fretting_20261104_v4_native_first`.

테스트: `python -m unittest test_global_fretting_hand test_fretting_hand_skeleton test_hand_anatomical_validity test_hand_fret_tracker test_hand_cell_distribution test_hand_frame_contract test_kim_hand_review test_cell_audio_fusion -q` —70개 통과. 원본의 강한 후보는 회전하지 않음, 원본에 선택됐어도 점수가 약하면 추가 회전함, 실제4812의 원본 보류 후 추가 회전으로 운지 손을 복구함을 검사했다. 너트 분포·손 묶음·좌표복원·기존 유효성 계약 검사도 통과했다.

# 새 손 선택 + 지판 + 오디오 + 화성 비교 — 2026-11-05

후속 정확도 검사: 화면 코드·TAB·실제 운지를 대조한 안정구간9개 평가는 [정답 비교 보고서](TUTORIAL_GROUND_TRUTH_COMPARISON_2026-11-05.md)를 참조한다. 아래18시점 결과는 정답 없이 후보 변화만 측정한 이전 실험이다.

**18개 시점에서 후보 순위를 비교했다. 오디오80%·시각20% 실험은 1위가1곳, 상위3개 목록/순위가7곳 바뀌었다. 정확도 향상률은 아직 계산할 수 없다.**

18개는 독립된18개 코드 이벤트가 아니다. 195~225초12개 샘플에4812와4821~4825를 추가한 개발용 표본이다. 같은 구간을 개발과 평가에 사용했으므로 일반화 성능 검사가 아니다.

## 두 결과를 구분

기존 엄격한 의미/기하 검증을 유지한 결과는18곳 모두 오디오 단독과 같다. 새 손 스켈레톤의 해부학적 타당성과 지판 정밀 기하가 미확정이기 때문에 실제 운지 근거로 승격하지 않았다. 기존 `cell_audio_fusion`의 차단 규칙은 수정하지 않았다.

별도 탐색 실험에서는 새 손 선택의 검지·약지·새끼 끝점을 잠정 지판/가상현 칸 분포로 옮겨, 코드 구성음과의 위치 호환성으로 오디오 후보를 재정렬했다. 중지 끝은 알려진 오류 때문에 제외했다. 나머지 세 손가락도 정확성이 검증됐다고 간주하지 않는다. 실제 눌림/개방현/뮤트/바레 다중접촉은 추론하지 않는다.

## 오디오와 시간 연결

기존3~12초 오디오는 이번 구간과 달라 재사용하지 않았다. 같은 원본 SHA256의194~226초를 기존 PTS/샘플 정합 추출기로 추출하고, 설치된 로컬 htdemucs 캐시로 보컬 분리를 실행했다. 새 설치/다운로드는 없었다. 분리 성공과 샘플 수는 확인했지만 이 새 구간의 사람 청음 검수는 아직 없으며 반주는 기타 단독이 아니다.

오디오 분석은 기존 spectral baseline과 화성 엔진을 사용했다. 각 사진에서 가장 가까운 단일 STFT 분석 프레임을 사용했고 최대 중심시간 차이는4.55ms다. 분석창 길이는8192/44100=약186ms로 전후 약93ms 소리가 포함된다. 서로 다른 시간의PC를 합치지 않았다. 실제 시청각 지연은 미검증이고 보정0이다.

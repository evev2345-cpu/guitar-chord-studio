# GuitarSet 마이크 음원 수신·정답 연결 완료

후속 평가 완료: 반주180개의 [오디오 기준 성적표](GUITARSET_BASELINE_BENCHMARK_2026-11-05.md)를 작성했다. 아래 평가 미시작 표기는 수신 검사 당시 상태다.

사용자가 GuitarSet 폴더에 넣은 `audio_mono-mic.zip`을 검사했다. 공식 Zenodo의 MD5 `275966d6610ac34999b58426beb119c3`와 일치했고 ZIP 전체 CRC 검사도 통과했다. 원본 ZIP/주석은 유지하고 `GuitarSet/audio_mono-mic`에360개 WAV를 풀었다. 경로/중복/심볼릭 링크 검사 후 새 폴더에 추출했다.

- 음원360개와 기존 JAMS360개가 파일명 기준으로 전부1:1 대응한다.
- 반주180개, 솔로180개, 총10,968.44초(약3.05시간)다.
-20ms 초과의 음원/주석 메타데이터 길이 차이는 없었다.
-6개 줄별 음표 트랙을 확인했고, 음원 범위를20ms 넘는 음표/음수 시작/비양수 길이 검사는 발견사항이 없었다. 이는 주석의 의미나 내부 시점 정확성을 모두 검증했다는 뜻은 아니다. 공식 알려진 시간 오류는 별도 확인이 필요하다.
- 기본 악보 코드와 상세 연주 코드 층을 별도로 식별해 기록했다.

아래는 첫 반주 파일의 실제 마이크 음원 파형, 줄별 음표 정답, 두 코드 층을 같은 시간축에 표시한 것이다. 음원을 모델로 분석해 새 예측을 만든 결과가 아니다.

![실제 음원과 원본 정답 연결 예시](../dataset/integration_review/runs/guitarset_audio_ready_20261105_v1/paired_example.png)

재현 스크립트는 `prepare_guitarset_audio.py`이며 기존 추출 폴더/완료된 결과가 있으면 덮어쓰지 않는다. 파일별 오디오/주석SHA256, 샘플 수·길이·채널, 연주자와 반주/솔로 구분은 `dataset/integration_review/runs/guitarset_audio_ready_20261105_v1/manifest.json`에 저장했다.

이번 작업은 수신 검증과 연결 준비까지다. 전체360개 코드 평가나 학습은 아직 시작하지 않았다. 다음은 반주180개에서 두 코드 층을 분리한 평가와 실제 음표 기반 기본음/배음 오류 평가를 구성하는 것이다. 기존 영상9개 결과와 새 데이터셋 결과를 섞지 않는다.

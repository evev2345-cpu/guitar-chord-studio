추가 API 호출 0회. 원본 12장, 저장된 지판 결과 17개(기존 12 + 경계 재검출 5).
동일 이미지의 MediaPipe 추론은 한 번만 실행하고 두 지판 버전에 재사용했다.
800×150, player=right, mirrored=unknown, 현 추정 비활성화. 기존 추적 로직은 변경하지 않았다.

## 원본·평탄 지판 시각 검토

- 운지 손 선택이 시각적으로 타당하고 프렛 후보가 생긴 이미지는 4장: 1051_5605_0000, 2012032601357_0, images (2), l_2014061102000525100136271. 후보 14개 중 보간 와이어를 경계로 사용하는 후보가 많다. 접촉이나 실제 프렛 번호의 정답을 확인한 것은 아니다.
- 1051_5603_0000, 1350562795380, 201801031717219410_1: 운지 손은 검출되지 않고 피킹 손만 검출됐다. 피킹 손이 selected가 되는 명백한 손 선택 실패. 네 끝점 모두 outside_board라 프렛 오배정은 없었다. 평탄 이미지에는 운지 손이 보이지만 골격은 없고, 원본에서는 피킹 손에 주황 골격이 있다.
- 1347539285769: 원본·평탄 지판에 손이 보이지만 MediaPipe 검출 0. images: 검출 0이며 지판 주변 손 자세도 일반적인 운지 장면과 다르다. 작은 손 크기·가림·무대 조명은 가능한 원인일 뿐 원인 분리 실험은 하지 않았다.
- 2015111201921_0: 두 손 검출, 점수 0.978/0.900. escgE1715241981 경계 버전: 두 손 검출, 0.894/0.969. 두 경우 모두 점수 차 <0.12로 선택 보류. 원본에서 운지 손은 식별 가능하지만 현재 평탄 지판 주변 거리 점수만으로 분리하지 못한다.
- images (1): 두 손은 검출됐지만 기존 마지막 21번 와이어의 하단 x=801.45358이 800 범위를 벗어나 지판 입력 검증에서 차단. escgE1715241981 기존 버전도 22번 하단 x=801.64로 차단됐다. 이 두 결과의 진단 이미지는 코너와 손만 사용하며 프렛선은 생략했다. 원본 저장 자료는 수정하지 않았다.

## 동일 이미지의 지판 버전 차이

- 1051_5605_0000: 검지가 기존 unresolved_fret_geometry → 경계 버전 1번 후보. 나머지는 2/3/3 유지. 보간 출처는 버전에 따라 달라진다.
- 2012032601357_0: 9/8/8/7 유지. 경계 와이어의 observed/interpolated 구성은 달라진다.
- l_2014061102000525100136271: 2/3/3/3 → 2/outside_board/3/4. 같은 랜드마크를 사용해도 지판 코너·와이어 추정이 바뀌면 칸과 영역 판정이 달라진다. 정답이 없어 어느 버전이 맞는지는 확정할 수 없다.
- 1347539285769: 양쪽 모두 no_hands. escgE1715241981: 기존 지판 검증 실패 → 경계 버전 지판 통과, 그러나 손 선택은 모호.
- 경계 재검출 버전은 코너와 와이어도 다시 추출한 결과이므로 차이를 경계 복원 코드만의 효과로 해석하지 않는다.

## 다음 수정 우선순위

1. selected를 성공으로 집계하지 말고 실제 지판 내부 후보 수와 운지 손 검출 여부를 분리한다. 피킹 손만 검출된 경우 선택을 보류할 근거가 필요하다.
2. 원본 지판 주변 ROI 확대 추론을 비교해 작은/가려진 운지 손의 검출률을 확인한다. ROI 랜드마크는 반드시 원본으로 복원한다.
3. 모호한 두 손에는 원본 영상의 지판 거리·너트/바디 방향·손바닥과 관절 정보를 추가한다. 반전 여부 미상에서 handedness를 강제하지 않는다.
4. 손/접촉/와이어 정답 라벨로 선택과 프렛 후보 정확도를 별도 검증한다.

## 산출물과 재실행

`python compare_hand_tracking.py` (로컬 추론만 실행).
각 결과별 .json, _original.png, _flat.png, _review.png. contact_sheet_1~5.jpg로 전 사례 확인 가능.
JSON의 hand_index는 이미지 내 인덱스이며 영상 추적 ID가 아니다.
invalid_cached_fret_geometry에서는 frets에 원본 기록을 보존하지만 진단 렌더링에 사용하지 않는다.
